# xiv2gen2

Original xiv2gen: https://github.com/otto9ns/xiv2gen

goatcorp/xivlauncher **unsecure** 2fa helper. It is *really unsecure*. By storing your 2fa secret in a file on the same device you use to launch the game, you are basically negating the whole point of the 2fa.

## Dependencies

- ``libcurl`` (``pacman -Sy curl`` on Arch Linux)
- ``liboath`` (``pacman -Sy oath-toolkit`` on Arch Linux)
